# Structural Scope of Work — Pod Type A
**For licensed Structural Engineer (SE) | 2026-09-30 | Preliminary**

## The Decision That Drives Everything

**Is the module transportable or permanent?**

| | Transportable (modular) | Permanent (site-built) |
|---|---|---|
| Design for | Highway loads, lifting, setting | In-place wind/seismic only |
| Foundation | Temporary piers / skids | Permanent foundation |
| Code | IBC + modular program (Illinois) | IBC standard |
| Connections | Inter-module + anchorage | Standard framing |

**Joe: this decision is needed before the SE starts.** It changes the entire
structural approach, the foundation, and the permit path.

## Scope for the SE

### 1. Gravity System
- [ ] Floor: verify capacity for concentrated loads —
  water unit (~150 lbs?), 5 kW heater, bunk berth (2 occupants + mattress),
  L-shelving with microwave/air fryer.
  - IBC Table 1607.1: 40 psf (residential sleeping) as basis; confirm.
- [ ] Bunk spine (4'×7'×10'): design as load-bearing partition —
  upper berth (Pod B) + lower berth (Pod A) + ladder loads.
- [ ] Roof: 20 psf live (IBC) + mechanical (ERV/hood exhaust caps).
- [ ] OEM plywood shell: verify grade/species/thickness for structural use.
  If the OEM multi-layer plywood isn't structural grade, specify replacement.

### 2. Lateral System
- [ ] Wind (Peoria, ~115 mph per IBC Fig 1609.3 — verify) — shear walls, holdowns.
- [ ] Seismic (SDC A/B — low, but detail per IBC Ch. 16).
- [ ] The 10'-tall × 20'-long walls need shear capacity — plywood sheathing
  schedule (nailing, holdowns at corners).

### 3. Pod-to-Pod / Pod-to-Spine Separation
- [ ] Structural separation vs. tied — affects acoustic/fire detailing.
- [ ] Differential movement (if transportable).

### 4. Heat-Treatment Consideration
- [ ] 140°F sustained: verify adhesive and plywood don't creep/degrade.
  (Standard wood adhesives are fine to ~140°F short-term, but 3-hr holds
  repeated over years need the SE's sign-off.)

### 5. Deliverables Needed from SE
- Foundation plan + details
- Framing plans (floor, wall, roof)
- Shear wall schedule + holdown details
- Connection details (spine-to-pod, module-to-foundation)
- Structural notes + special inspections list

## Information the SE Will Need from Joe
1. Transportable or permanent? (see above)
2. Site: soil report (geotech), flood zone, exposure category.
3. Stacking: single-story or multi-story? (Affects everything.)
4. OEM plywood spec sheet (grade, thickness, species).
